# 连云港市东海县道路交通事故统计与可视化分析系统

单机版（Windows 10）/ Python + Flask + SQLite + ECharts 实现的本地浏览器应用。
面向交警业务部门：事故信息录入、台账查询、多维统计、可视化大屏、Word 月报导出。

> **地域定位**：本系统已针对 **江苏省连云港市东海县**（行政区划代码 320722）本地化——
> 辖区字典为东海县实际下辖的街道/乡镇，演示数据的道路、车牌（苏G）、坐标均落在东海县范围内，
> 数据驾驶舱地图默认展示**东海县街道/乡镇**视图，并可叠加**真实路网**（见下文「关于地图」）。

## 一、快速开始（Windows 10）

1. 安装 Python 3.9+（[官网下载](https://www.python.org/downloads/)，安装时勾选 **Add to PATH**）
2. 双击项目根目录下的 **run.bat**
   - 首次运行会自动：下载 ECharts、安装依赖、初始化数据库、生成约 1500 条演示数据
   - 之后启动只需双击该脚本，浏览器会自动打开 `http://127.0.0.1:5000`
3. 登录账号
   - `admin / admin123` — 管理员（全部权限）
   - `recorder / 123456` — 录入员（录入、修改）
   - `viewer / 123456` — 查看者（只读，给领导用）

### 关于地图（高德式离线瓦片地图）

驾驶舱地图采用 **Leaflet + 本地离线瓦片**，体验与高德/谷歌一致：
**可平滑缩放、越放大越能看到街道级细节**，事故点（按等级着色）/ 热力图叠加在真实底图上，
可切换散点/热力、开关县界描边。全程离线、无需任何地图密钥。

地图数据分两部分，在**能联网**的机器上各运行一次脚本即可（之后整套拷到离线机使用）：

**① 离线瓦片底图（实现“可缩放看街道”，必需）**

```
python download_donghai_tiles.py
```

- 默认下载东海县街道级瓦片：全县 z10–15 + 县城核心区 z16–18，约 1.7 万张、**约 300MB**
- 保存到 `tiles/{z}/{x}/{y}.png`，程序通过 `/tiles/...` 离线读取；支持**断点续传**，中断重跑即可补齐
- 来源 OpenStreetMap 瓦片（ODbL）。如有自建/授权瓦片服务（含天地图离线包），改脚本里 `TILE_URLS` 即可
- 没有瓦片也能用：显示县界 + 事故点，底图留白并给出提示

**② 县界 / 路网矢量数据（用于县界描边，可选）**

```
python download_donghai_map.py
```

| 文件 | 内容 | 来源 |
|---|---|---|
| `donghai.json` | 东海县县界（叠加描边） | 阿里 DataV.GeoAtlas |
| `lianyungang.json` | 连云港市各区县边界 | 阿里 DataV.GeoAtlas |
| `donghai_roads.json` | 东海县真实路网（矢量，备用） | OpenStreetMap（Overpass API） |

> 为什么不用天地图/高德在线地图？它们是**在线瓦片服务、运行时必须联网且需密钥**，
> 不提供可离线保存的底图——部署到无外网内网机后地图会空白，与“单机离线”冲突。
> 本方案把瓦片提前下好随程序分发，因此离线也能获得同样的缩放体验。
> 地图引擎 Leaflet 由 `download_libs.py` 与 ECharts 一并下载到 `static/`。

### 关于现场照片

- 在事故详情页或编辑页上传
- 单条事故最多 10 张图片，单张 ≤ 5MB
- 支持 JPG / PNG / GIF / BMP / WEBP
- 图片文件存储在 `uploads/<事故ID>/` 目录
- 数据库只存文件名，库不膨胀

### 关于批量导入

- 事故台账页 → 「批量导入」按钮
- 先下载标准 Excel 模板，按格式填写
- 上传后逐行解析，单行失败不影响其他行
- 显示成功 / 失败统计 + 失败行明细
- 涉事车辆 / 人员暂不支持批量导入

## 四、数据库表

- `users` 用户（id / 用户名 / 密码哈希 / 角色 / 姓名）
- `accidents` 事故主表（25 个字段，含时间、地点、伤亡、原因等）
- `vehicles` 涉事车辆（一对多）
- `persons` 涉事人员（一对多）
- `dictionaries` 字典（13 类下拉项）
- `operation_logs` 操作日志

关键字段加了索引：`occur_time / district / level / type / road_name`，10 万级数据查询无压力。

## 五、给领导演示的几个亮点

1. **数据驾驶舱**首屏 4 个 KPI 卡（事故 / 死亡 / 受伤 / 损失）+ 同比涨跌
2. **月度趋势图**自带涨跌势对比，支持切换 3/6/12/24/36 个月
3. **时段热力图**直观展示事故高发时段
4. **TOP 路段排行**自动定位事故多发点
5. **Word 月报**一键生成，含同比分析、TOP 排名、重大事故清单、工作建议——可直接打印呈报

## 六、打包成 EXE（可选）

无需手动写命令，直接双击 **build.bat** 即可：

```
build.bat
```

或在命令行：

```
python build_exe.py
```

脚本会自动完成：安装 PyInstaller → 检查 ECharts 文件 → 清理旧产物 → 打包 → 生成 `dist/道路交通事故统计与可视化分析系统.exe`（约 30MB 单文件）+ `dist/使用说明.txt`。

**打包后的运行说明**：

- 双击 exe 启动，浏览器自动打开
- 首次运行会在 exe 同目录下自动创建 `data/`（数据库）、`uploads/`（照片）、`backup/`（自动备份）
- 把 exe + 这三个目录一起分发即可
- exe 启动较慢（约 5-10 秒，PyInstaller 单文件需解压），正常现象

## 七、常见问题

**Q: 如何重置全部数据 / 重新生成演示数据？**
A: 关闭程序，删除 `data/accidents.db`，重新启动即可。

**Q: 如何完全离线（无网络）部署？**
A: 在有网机器上完成首次 `run.bat`（已下载 ECharts、安装依赖），把整个目录连同 Python 安装一起拷贝到目标机器。或者使用「打包成 EXE」方式。

**Q: 数据备份位置？**
A: 启动时自动备份到 `backup/auto_yyyymmdd.db`，保留 30 天；管理员可在「用户与日志」页手动备份。

**Q: 默认密码必须改？**
A: 是。管理员登录后到「用户与日志」页重置 admin 密码，并删除不需要的演示账号。
